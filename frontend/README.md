# NexusRAG Frontend

This frontend has been migrated from Create React App to Vite and now serves as the presentation layer for the `NexusRAG` workspace experience.

## Core UI Capabilities

- Workspace creation and switching
- Multi-document uploads into a shared context
- Split-screen evidence viewing for PDFs
- Streaming chat responses over SSE
- Markdown, table, and code block rendering with copy actions

## Development

```bash
npm install
npm run dev
```
